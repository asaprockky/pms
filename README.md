# PMS — Web & Service Architecture Sample

A sample TypeScript codebase structure showcasing frontend views and backend NestJS module patterns.

## Project Structure

- `packages/backend`: Node.js NestJS API service architecture with Prisma ORM data layer.
- `packages/web`: React client dashboard views and UI components.
- `packages/mobile`: React Native mobile view stubs.

## Installation & Setup

```bash
npm install
npm run build
```
